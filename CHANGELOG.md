# Changelog

Railway template updates are opt-in: when a change lands, everyone running this
template is asked whether to apply it, and this file is what they decide from.
So entries are written for that decision — what changes for you, and whether you
have to do anything — rather than as a list of commits.

Anything needing action after taking an update is called out as **Action
required**, not left as a bullet to notice.
